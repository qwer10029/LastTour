# 终末旅行（End Journey）

> PC 端 2D **生存经营 + Roguelike** 游戏概念设计仓库

战争摧毁了一切，城市被迫垂直生长。你在废墟与遗弃的军械之间独自向上，只为兑现一句模糊的承诺：**上层，有人在等。**

---

## 游戏简介

**终末旅行**是一款单人 PC 游戏。每局从零开始，玩家选择不同**分队**获得开局加成，驾驶燃料有限的车辆在战后城市中探索、搜集资源并抵御威胁，以车辆为夜间据点。历经五层城市，逐层缴纳电梯通行费向上攀登，抵达最顶层即为本局通关；失败则重来，地图与遭遇随机变化。

| 项目 | 说明 |
|------|------|
| **类型** | 生存经营 + Roguelike |
| **呈现** | 2D 平面 |
| **平台** | PC（单人） |

## 核心玩法（摘要）

- **白天**：驾驶车辆在 2D 地图上探索，搜集资源，遭遇事件与 NPC，抵御外敌
- **夜晚**：以车辆为据点休息，需布置防线，否则资源可能被盗
- **逐层推进**：在当前层探索 → 找到电梯 → 缴纳通行费 → 进入上一层，共五层
- **Roguelike**：单局制、随机地图与遭遇、开局分队与难度选择，支持多次重玩
