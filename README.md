# 终末旅行（End Journey）

> PC 端 2D **生存经营 + Roguelike** 游戏概念设计仓库

大战灭绝了人类，地下据点也已覆灭，唯有「昆仑」勘探程序仍在向地表派遣克隆人。你是地表 **唯一的人类**，驾驶车辆在废墟中向上，为早已无人接收的终止信号而战。

---

## 游戏简介

**终末旅行**是一款单人 PC 游戏。每局从零开始，玩家选择不同**分队**获得开局加成，驾驶燃料有限的车辆在战后城市中探索、搜集资源并抵御威胁，以车辆为夜间据点。历经五层城市，逐层修复受损电梯向上攀登，抵达最顶层即为本局通关；失败则重来，新的克隆人再次出发。

| 项目 | 说明 |
|------|------|
| **类型** | 生存经营 + Roguelike |
| **呈现** | 2D 平面 |
| **平台** | PC（单人） |
| **核心体验** | 紧张生存 · 唯一人类的孤独旅途 · 反战主题 |

## 核心玩法（摘要）

- **白天**：驾驶车辆在 2D 地图上探索，搜集资源，触发遗迹事件，抵御外敌与失控机械
- **夜晚**：必须回车停泊；布置防线以应对 **环境恶化**（辐射、低温等）与 **战前自动回收系统**，否则车外物资与车辆会受损
- **逐层推进**：在当前层探索 → 搜集资源修复电梯 → 进入上一层，共五层
- **Roguelike**：单局到顶可留言归档；跨局累计五层档案，集齐后顶层三选一终局（停机 / 只留言 / 伪造成功）
