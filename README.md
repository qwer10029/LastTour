# 终末旅行（End Journey）

> PC 端 2D **生存经营 + Roguelike** — 设计文档 + 可玩原型

大战灭绝了人类，地下据点也已覆灭，唯有「昆仑」勘探程序仍在向地表派遣克隆人。你是地表 **唯一的人类**，驾驶车辆在废墟中向上，为早已无人接收的终止信号而战。

| 项目 | 说明 |
|------|------|
| **类型** | 生存经营 + Roguelike |
| **呈现** | 2D 平面 |
| **平台** | PC（单人） |
| **引擎** | Godot 4.6 + GDScript |
| **核心体验** | 紧张生存 · 孤独旅途叙事 · 反战主题 |

## 快速开始

### 运行游戏

1. 安装 [Godot 4.6](https://godotengine.org/)（GL Compatibility 即可）
2. 用 Godot 打开 **`game/project.godot`**
3. 按 **F5** 运行；主场景为 `scenes/menu/main_menu.tscn`

### 直接试玩（无需 Godot）

运行 [`终末旅行-0622.exe`](./终末旅行-0622.exe)（Windows 导出包，位于仓库根目录）。

### 基本操作

详见 [docs/dev/游戏快速上手指南.md](./docs/dev/游戏快速上手指南.md)。简要：

- **WASD**：驾驶 / 室内步行
- **E**：下车进入建筑、交互
- **傍晚 F**：进入夜晚塔防布防
- 靠近物品自动拾取；搜集零件修复电梯，逐层向上

## 游戏简介

**终末旅行**是一款单人 PC 游戏。每局从零开始，玩家选择**难度**与**分队**获得开局加成，驾驶燃料有限的车辆在战后城市中探索、搜集资源并抵御威胁，以车辆为夜间据点。修复电梯逐层向上攀登，抵达顶层昆仑控制中心即为本局通关；失败则重来，新的克隆人再次出发。跨局在终端累积 NPC 遭遇情报，拼齐真相后可进入三选一终局。

### 核心循环

| 时段 | 玩家行为 |
|------|----------|
| **白天 / 傍晚** | 驾驶探索、下车搜集资源、遭遇智能机器 NPC 与剧情事件 |
| **夜晚** | 回车停泊，进入实时俯视角塔防，部署 7 种防御设施抵御波次敌人 |
| **层间推进** | 搜集零件修复电梯 → 进入上一层（原型 **3 层**；完整设计目标 5 层） |

### 已实现原型（摘要）

- 主菜单、难度/分队选择、开场序章与新手教程
- 程序化世界地图 + 驾驶/步行双模式探索
- 资源、背包、燃料、昼夜循环
- 夜晚塔防：7 种设施、多种敌人、波次、能源调度、策反与指挥官 AI
- 多条 NPC 剧情线、勘探日记、跨局 Meta 存档
- 顶层通信终端与终局流程框架
- PC 导出配置（见 `game/export_presets.cfg`）

## 技术概览

| 类别 | 选型 |
|------|------|
| 引擎 / 语言 | Godot 4.6 · GDScript |
| 数据驱动 | JSON（塔、敌人、波次、对话、剧情、物品） |
| 跨局存档 | `user://meta.json`（MetaManager） |
| 版本控制 | Git |

**塔防子系统亮点**（详见 [最终游戏报告.md §3.3](./最终游戏报告.md)）：

- **流场寻路 + 多源 Dijkstra**：大量敌人 O(1) 采样方向，优于逐单位 A*
- **威胁影响图**：火力场注入寻路代价，高难度敌人绕开炮塔
- **指挥官多流场 AI**：集结、攻坚、佯攻
- **空间哈希分离转向**：群体移动 O(n) 分散，避免长龙堆叠
