# 场景转换
现在的文档里是人和车一直在一起，这样节约燃料这一点无从实现。应该是车只在路上移动，探索时人会下车进入建筑物，步行收集资源再搬到车上。即“白天探索”这个场景需要拆开，分为两种状态，1是驾驶车辆，使用横板的模式，玩家从车辆前进方向的右侧观看车辆行进，在背景里展示建筑物、废墟等环境，2是步行探索，应该是一个俯视图的模式，展示人物和周围环境的细节。![alt text](move_and_collect.png)
# 随机地图生成
这是rogue-like游戏的核心机制，地图应该直接做随机生成的，没必要先手动再生成。每次进入一个新的区域，地图都会重新生成。

# 地图
这里没提到，但考虑作为类似帝国时代，红色警戒那样，屏幕大部分区域是当前所在区域能看到的内容，仅为完整地图上的一个可以滑动的窗口。玩家需要通过探索来逐渐打开地图，看到更多的内容。右下角显示全局的缩略图，已探索地图为亮色，且注明资源信息，未探索地图为黑色，玩家所在位置有一个标记。这是帮助玩家对当前层进行遍历，从而保证能在有限时间内发现电梯的条件。
