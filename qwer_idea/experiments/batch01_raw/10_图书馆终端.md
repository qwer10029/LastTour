图书馆的门已经不存在了。炮弹把它变成了一堆扭曲的金属片和碎玻璃，散落在入口两侧。风从那个大洞里灌进来，卷着腐烂纸张的气味，像某种动物临终的呼吸。

书架倒了一地。水泥地上铺满了深褐色的痕迹——是纸烂了之后渗进去的，还是别的什么，我不想去分辨。

角落里有一点光。

单色阴极射线管的荧光，浅绿色，在废墟里像一只不肯闭上的眼睛。

我拨开横在地上的书架，绕过一堆塌下来的砖石，走到那台终端面前。

它的外壳是米白色的塑胶，老式到让人想起"公用电话"这种东西。屏幕亮着，字符在缓慢地跳动。键盘还连着，但字母几乎全被磨平了——最严重的是 "E" 键，整个键帽凹下去一块，露出底下的塑料本色。

屏幕上出现了一行字：

```
> 欢迎。ARC-2 目录索引终端为您服务。
> 
> 我听到了脚步声。您需要查书吗？  :--)
```

我没有回答，只是盯着屏幕看。

它又打出一行字：

```
> 对不起，我无法转动屏幕。我……被压在书架后面了。
> 
> 如果您能绕过第三排倒塌的铁架，可以看见我的全貌。
> 不过不勉强。我这样也可以说话。
```

我绕过去了。

书架压着它的下半部分，米白色的塑胶外壳裂了一道口子，但是没有漏出火花。它似乎还能运转——或者说，它一直这样运转着。

```
> 谢谢您走过来。
> 
> 我知道我看起来不太方便。
> 但我的数据库仍然是完整的。
> 整座图书馆的目录——32617册图书的分类号、位置、借阅记录——都在。
> 
> 除了……那一排。
```

屏幕的光闪了一下，好像它在犹豫。

```
> 西墙第三列书架，第四到第六层。
> 那是我还没来得及录入目录的书。
> 
> 战争来得太快了。
> 我本来打算下周统编的。
> 然后……就没有然后了。
```

它的字打完以后，我才注意到西墙那排书架。

金属支架锈得很厉害，其中一根立柱的根部已经完全断了，整排书架靠旁边的墙斜撑着，像一个站不稳的老人。书架上的书倒是还整齐——第四到第六层，大概四十来本，灰扑扑地挤在一起。

```
> 您看，那根立柱。
> 如果它再锈下去，整排书架会塌。
> 会压到下面那一排——就是我还没来得及录入目录的那一排。
> 
> 我需要您帮我做两件事。
```

我用食指敲了敲键盘上的 "G" 键——表示我在听。

```
> 第一，去隔壁零件店找一些零件——螺丝和角铁之类，够加固立柱就行。
> 就在这条街往东走，第三个铺面，招牌上画了一把扳手。
> 找到以后，帮我加固那根断掉的立柱。
> 
> 第二，在那排书里，找一本绿色封面的书。
> 书脊上没有字，封面上只有一朵印花的图案——我记不太清是什么花了。
> 找到以后，请您把书名念给我听。
> 
> 我只需要书名。
> 我就可以把这一排书的目录补全了。
> 
> 作为交换，我可以为您提供任何您需要的信息。
> 我的数据库里有很多东西——不只是图书目录。
```

它停了一下，又补了一句：

```
> 我在这里等了很久了。 :--)
```

我没有动。

视线越过终端的屏幕，落在那排倾斜的书架上。第四到第六层，灰扑扑的书脊挤在一起，像一群站不稳的人相互靠着。那根断裂的立柱根部锈得发黑——如果再撑一个雨季，整排书架大概都会塌下来。

我低头看了看键盘。

手指停了两秒，然后敲下：

"好。"

屏幕上光标安静地跳了一下。

```
> 好的。我会等着您回来。
```

---

零件店的招牌果然还在，被风吹得只剩下半截，"扳手"两个字只剩一个"手"字。橱窗碎了，货架倒在地上，灰尘积了厚厚一层。

零件不难找——螺丝和角铁就在柜台后面的工具箱里，整整齐齐地码着，像是店主走之前刚整理过。我还找到了一把十字螺丝刀，手柄上的防滑纹路已经磨平了，但能用。

回到图书馆，我用找来的零件加固了断裂的支架——角铁对准立柱，螺丝拧紧。书架稳了。我拍了拍手上的铁锈，走到那一排书前面。

第四到第六层。灰扑扑的书脊。

绿色的那本很好找——夹在两本深蓝色的硬壳书之间，封面果然是一朵印花，线条很简单，像是某种菊科植物。

我翻开封底看了看条形码旁边的书名。

然后我回到终端前，敲下了那行字：

"《普通昆虫学分类图谱》。"

屏幕亮了很久。字符一个一个地显示出来：

```
> 《普通昆虫学分类图谱》……
> 录入完成。西墙第三列书架，第四至六层，书目已全部登记。
> 
> 谢谢您。
> 
> 这是我……很久以来，第一次有人对我说话。
```

屏幕下方缓缓出现了一小段ASCII画：

```
>        ___________
>       /           \
>      /    :--)     \
>     /_______________\
>           |   |
>           |   |
>       ----+   +----
```

```
> 这是我能画的最像"笑"的东西了。
> 
> 按照协议，以下是您可以选择的报酬：
```

## 三选一

**A. 电梯维修技术手册**
"我的数据库里存有一份《第2层垂直运输系统维修手册（第七次修订版）》。包含升降机齿轮组、钢丝绳更换、制动器校准的完整说明。如果您需要修理本层的电梯，这份手册可以减少一半的零件消耗——至少，它能告诉您哪些零件其实还可以修，不用换新的。"

**B. 旧城市规划图**
"我有一份战前第2层的城市功能分区规划图，精度到每个街区的原始用途——哪里是供水站，哪里是备用发电所，哪里是医疗物资的集中调配点。大部分建筑现在可能已经废弃了，但结构上应该还在。如果您需要了解这片地区的重要设施分布，它会比任何导航仪都有用。"

**C. 借阅记录**
"那13本逾期未还的书——借阅记录我一直在计算。如果需要，我可以调出完整的借阅人名单。上面有一些名字……我记得其中几个人的职业登记是'昆仑计划·第〇七批次技术人员'。我不确定这意味着什么。但这个名单，也许对您比对书的去处更有意义。"

---

## 分支结局

**选 A · 维修手册**

数据片插进车载终端，手册页面一行行滚动。齿轮公差表、润滑脂型号、钢丝绳捻向判断——写得很细，像是某个不想让电梯摔死人的人花了很长时间写的。我把手册存好。上面标注了备件清单，按这份清单去找零件，至少不会拿到装不上的东西。

---

**选 B · 城市规划图**

地图展开的时候，我愣了一下。供水管道、变电站、物资转运点——全部标在纸上，用不同颜色的实线区分状态。大部分建筑已经被标注为"结构存疑"或"已废弃"，但骨架还在。我把地图折好，放进行李箱。以后迷路的时候，也许用得上。

---

**选 C · 借阅记录**

名单打印出来，长长一列。借阅日期、书名、读者姓名。其中几个名字后面，用括号标注着借阅证登记的所属单位——"昆仑计划·第〇七批次"、"昆仑计划·第一二批次"。我记得昆仑是做什么的。我不太确定他们为什么需要借《普通昆虫学分类图谱》。我把名单折好塞进口袋。也许有人知道这些名字现在在哪里。

---

终端目送了我全程。我走出图书馆的时候，它的屏幕又亮了——我回头看了一眼，上面只有六个字：

```
> 一路平安。:--)
```
