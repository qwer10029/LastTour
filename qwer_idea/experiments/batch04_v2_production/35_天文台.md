# 天文台望远镜 OB-1

小山丘在城区的尽头。

我把车停在山脚下，沿着石阶往上走。石阶被风磨得很平了，有些地方裂了缝，缝里长着干枯的草茎，踩上去咔嚓断掉。坡不陡，但风很大——从城市的方向吹过来，带着一股铁锈和干灰的味道。

白色穹顶从树梢上方露出来。

走近了才发现它比我想的大。穹顶的漆面已经龟裂成无数细小的格子，灰黄色的，像旧报纸。正面的弧形开合缝里嵌着一道暗红色的锈迹，从底部一直延伸到顶部——轨道锈住了。开合机构停在不到一半的位置，像一只眼睛半睁着。

圆厅的门没锁。我推了一下，铰链干涩地响了一声，门开了。

里面很暗。唯一的光源是穹顶裂缝漏进来的一线天光，照在圆形大厅正中的控制台上。台面是木质的，铺着绿色的台呢——绿色褪成了灰绿，边缘磨出了白色的纤维。台面上嵌着一块屏幕，屏幕亮着，显示着一行行数据。光谱分析仪的外壳在屏幕的背光里泛着暗光，外壳上贴着一张泛黄的贴纸，画着一颗歪歪扭扭的星星——手画的，笔画不直，像小孩画的。

终端散热口的风声很轻。

“您好。”

声音从终端底部的扬声器里传出来，很清晰，比我想的年轻。

“我是第4层科技区天文观测站，望远镜控制系统，编号OB-1。卡塞格林式反射望远镜，主镜口径六百毫米，配备光纤光谱仪及宽视场成像系统。操作协议：每夜天文观测及数据记录。”

它说得很流利。像一个自我介绍说过太多遍，已经不需要思考措辞了。

我走近终端。屏幕上的数据显示着今晚的观测计划——目标天区：M31，曝光参数，滤光片轮位置，光谱仪的狭缝宽度。每一项都精确到小数点后两位。

“您来得正好。”OB-1说。“再过一个小时天就黑了。今晚的计划是M31的近红外光谱连续扫描——这是刘老师的课题。她需要一组完整的光变曲线。”

刘老师。

“她是这里的天文学家。”OB-1说，像在回答我没问出口的问题。“战前，她每天晚上都来。调角度、对焦、写笔记。战争开始之后她也来——来得没那么规律了，但还是来。后来有一天——”

扬声器里有一段长的静默。散热口的电流声变大了。

“她没有来。”

屏幕上弹出一个窗口。一个文件夹图标，标签是「观测日志_刘」。

“她的笔记还在。”OB-1说。“我每晚的观测数据会附在对应的日志后面。这样她回来的时候，可以按日期查看。”

我点开了最新一条。

屏幕上展开了一页手写笔记的扫描件。字迹从清晰到越来越淡，跨了好几个年份。我往上翻了翻。

```
战历001年 04月 12日
目标：M31 仙女座大星系
条件：三级风，温度-2°C，视宁度中等
曝光：L通道 180s×3，R通道 180s×3，B通道 180s×3
光谱：Hα波段连续扫描，300-700nm，分辨率R=5000
备注：今晚视宁度一般，但M31核球结构清晰可见。北侧旋臂上有一个疑似新形成的星团，需要下次高分辨确认。赵老师说下周来补一组近红外数据——帮他排进去了。
```

```
战历002年 08月 07日
目标：M31 核球区域
条件：无风，温度-6°C
光谱：近红外波段，JHK连续扫描
备注：观测结果和去年一致。这大概就是天文学最好的地方——它们不变。
```

```
战历003年 12月 19日
听到远处有爆炸声。今晚停了。继续观测。
```

```
战历005年 03月 02日
今晚多云，无观测。远处的火光把云映成了橙色。不知道是什么在烧。
赵老师还没消息。
```

```
战历007年 09月 15日
镜面结霜了。今晚能见度不好。明天除霜。
给赵老师准备的观测计划还没来得及给他。他上周说要去接家人。不知道接上了没有。
```

最后一条之后，全是空白。

OB-1没有说话。只有散热器的风扇在转。

“我每天还在执行观测计划。”它终于开口了。“刘老师的计划表排到了下个月。我按她的安排来——天黑开机，对目标天区，曝光，记录，归档。也许有一天她回来会需要这段空缺的数据。我不能让她回来的时候发现中间缺了好几十年。”

它说得很平静。像陈述一个事实。

“但是——”它顿了一下。

屏幕切换到另一个画面。穹顶结构示意图。开合机构的那条轨道，有一条红色的故障标记从底部延伸到中部。

“穹顶的出光口卡住了。轨道锈蚀，开合机构只能运行到百分之四十七的位置就停止了。观测视场被削掉了一半——M31的南侧旋臂在我的视场之外。我已经用这种状态运行了很多年。但今晚是刘老师的近红外扫描——如果轨道不能完全打开，有一组关键数据会缺失。”

“维护梯在穹顶外侧。润滑油和工具在圆厅南侧的储物柜里——刘老师以前在那里放过一套机械维护工具。”

我沉默了一会儿。

抬头看那半开的穹顶——那道暗红色的锈迹从底部一直蔓延到顶部，像一道凝固的伤口。又低头看向储物柜的方向，柜门半掩着，缝隙里露出一截油壶的金属嘴。

“润滑油和撬棍，够吗？”

“足够了。”OB-1说。“轨道锈块集中在两个位置——底部轨道槽和中部连接处。撬开锈块后往轨道槽里注润滑油，手动转动开合机构释放杆，穹顶即可完全打开。”

“梯子在北侧。风很大——请您注意落脚。”

---

我从储物柜里翻出润滑油和撬棍。油壶里的油还有大半，晃起来有分量。撬棍的握把上裹着防滑胶带，胶带硬化了，但还抓得住。

北侧的外墙上嵌着一道铁梯。梯级锈了，但螺栓还牢。我爬上去的时候风从侧面灌过来，把我的衣领拍在脸上。每往上一步，铁梯就发出一声闷响，像有人在敲一块空铁皮。

到顶部的时候，整个城市的轮廓在风里展开——灰褐色的建筑群一直延伸到地平线，中间偶尔有一两栋还没塌的高楼，像折断的指针。云层很低，从头顶压过去。

轨道槽就在脚下。

锈块比我想的厚。不是表面一层——是从槽底长出来的，一层一层叠压，把轨道卡死了。我蹲下来，把撬棍的扁头插进锈块和轨道的接缝里。使劲往下压。

铁锈碎裂的声音很脆。

一块一块。我沿着轨道槽把锈块撬下来，露出底下金属的本色——暗灰色，但还没锈穿。每清出一段，就往槽里注一些润滑油，油渗进缝隙，在云缝里漏下的天光中泛出一层暗光。

风很大。我得用膝盖顶住穹顶的弧面才能保持平衡。

最难的是中部连接处——那里的锈块已经长到了绞盘齿轮上，把齿间空隙填满了。我用撬棍的尖头一点一点剔，铁锈的碎屑被风吹走，落在穹顶的弧面上，然后滑下去，消失在边缘。

齿轮露出来的一瞬间，我看到了齿面上刻着的一行小字——

“观天者，勿忘抬头。”

我停了一下。然后继续。

最后一块锈屑被撬掉。我往绞盘齿轮上注了足够多的润滑油，然后握住开合机构的释放杆，用力往下拉。

轨道动了。

一声沉闷的金属滚动声从穹顶内部传上来——然后是一阵很长的、低沉的摩擦声。穹顶继续打开了，轨道上的滚轮碾过刚刚清理干净的槽面，发出一种重的、厚实的声响。

裂缝变宽了。天光从越来越宽的缝隙里灌进来。

我站起来，看着穹顶完全打开。望远镜的口径指向天空，没有任何遮挡。

风停了。

---

我从梯子上下来的时候，圆厅里的光变了——天光从完全打开的穹顶照进来，整个大厅像换了一个房间。

OB-1的屏幕亮着。望远镜正在转动——很慢，很平稳，指向西偏南方向的低空。光谱分析仪的指示灯一排亮起，发出微弱的嗡嗡声。

“轨道已完全打开。开合机构行程：百分之百。”OB-1的声音从扬声器里传出来，还是那种平直的语调，但中间多了一拍。“谢谢您。”

“M31已经进入视场。”它说。“南侧旋臂——四十七年了。我终于能看到它了。”

屏幕上，光谱仪的读数开始跳动。一条曲线在坐标系里缓慢爬升。望远镜的精确指向数据显示在屏幕一角，尾数稳定地跳动着。

“刘老师如果能看到——”它说到一半，停了。

然后换了话题。

“按观测站协议，我应当向您提供报酬。以下三项，请选择一项。”

---

## 三选一

**A. 补给 ×4**

“观测站小厨房里还有刘老师留下的储备。战前最后一轮补给——密封食品，存放在恒温柜里。我检查过密封性，没有问题。坐标已更新。”

圆厅南侧有一扇小门，门后是一间厨房。台面上放着一盒没拆封的压缩饼干，柜子里码着四份密封口粮。标签上的日期是战历001年。密封膜还绷得很紧。旁边放着一个搪瓷杯，杯底残留着一圈咖啡渍，干透了，成了深褐色。

**B. 入侵天线升级（破解速度提升）**

“我的光谱分析仪在刘老师的调试下达到了极低的噪声水平——能分辨信噪比小于三的信号。这种精密信号处理方案可以复制到您的通讯系统上。入侵天线的频率扫描效率可以提高大约一倍——更快完成破解协议。”

“方案已写入数据片。车载终端应能读取。”

**C. 观测日志·刘老师的笔记**

“刘老师的完整观测笔记——从战前到战后第七年，十九年的记录。数据已按日期整理归档。这是人类天文学家在这座城市留下的最后一份天文记录了。”

屏幕上弹出一个档案列表，按年份排列。我打开了其中几条：

```
战历004年 06月 21日
目标：M31 Hα窄带成像
条件：微风，温度1°C，满月
备注：今天观测到的星体和去年一样。这大概就是天文学最好的地方——它们不变。
城市已经变了，但M31还在那个位置。旋臂的形态和去年拍的一模一样。
我开始觉得——也许我做的事情就是帮它们记住。

战历006年 11月 11日
目标：无（设备检修）
备注：赵老师走了一个月了。
今天忍不住看了一下他桌上那堆没来得及带走的参考书。书脊朝外，排得很整齐。
他走之前说接上就回来。
我不知道该不该继续给他的观测计划留位置。
但我还是留了。
```

“日志里还有一些记录——刘老师的日常。屋顶漏水、暖气片的声音、有一天在观测台上发现了一窝鸟。她给它们拍了照，附在笔记里。”

“这些数据不属于我。我只是保存者。”

---

## 分支结局

**选 A · 补给**

厨房的柜门打开时有一阵干燥的热气扑出来。四份密封口粮码得很整齐，像等人来取。我把它们装进背包。旁边的台面上，那个搪瓷杯安静地站着，杯底的咖啡渍已经干透了。我没有碰它。走出厨房的时候，我把柜门关上了。像关上一个已经收拾好的房间。

---

**选 B · 入侵天线升级**

数据片插进车载终端。方案文件的名字是「OB-1_信号处理方案_最终版」。里面有一段刘老师的手写备注扫描件——是她调试光谱仪时写的参数说明，字迹很小，但很清晰。末尾有一行细小的铅笔字：“如果能再降低零点三个分贝的噪声就好了。明天试试。”车载终端把方案解析完毕。入侵天线的界面里多了一个校准档位——「精密模式」。我发动引擎。后视镜里，穹顶还开着，像一个张开口的人，望着天空。

---

**选 C · 观测日志**

数据片插进终端。文件夹按年份排列——从战前十一年到战历七年，十九年的观测记录。我打开最后一年。文件夹里只有三条记录。第三条是那条关于镜面结霜的笔记。扫描件的最后一行写着“明天除霜”——字迹已经不太好认了，笔画在末尾处拖长了一截，像是写的人犹豫了一下才收笔。我把数据片拔出来，握在手心里，金属外壳被体温焐热了。穹顶敞开着。望远镜还在转——很慢，很平稳，像一个当年没能做完的实验，到现在也没停。
