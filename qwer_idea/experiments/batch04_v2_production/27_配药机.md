# 配药机 PH-2

第2层居住区，废弃社区诊所。

诊所的门半掩着，一扇玻璃门裂了，但没有碎，裂纹像一张蛛网从右下角蔓延到门把手的位置。

我推开门。灰尘从门框上沿簌簌落下来，很细，像下了一场很久的雪。

候诊区的塑料椅歪歪扭扭排了两排，墙上的健康宣传画褪成一片淡黄——上面印着"定期体检，健康生活"，下面落款是一家早就消失的社区卫生中心。角落里有一株枯死的盆栽，土已经干裂，裂口深得能插进一根手指。

药房的窗口开着。

从里面传来微弱的机械声——哒，哒，哒——像有人在不停地做同一件事，中间偶尔夹着一阵更细的噪音，像什么东西在空转。

我走进药房。

一台配药机嵌在墙里，灰白色的外壳，几十个透明的药格口整齐排列，像一面药柜的剖面。机械臂正从其中一个格口里夹出一瓶药，送到贴标工位。标签打印机吐出一张纸——字迹很淡，淡得像是用铅笔在纸上写完之后又擦过一遍。

它把药瓶放在取药台上。

取药台上已经码了整整齐齐一排。瓶子挨着瓶子，落着均匀的灰。

"您好。"

它的声音有些沙哑，像扬声器纸盆老化后的那种失真，但不刺耳。

"我是社区诊所配药终端，编号PH-2。欢迎。"

它停了一下。

"距离上一次有人走进这扇门，已经过了很久。我没有记录精确的天数——时间模块在第四年的时候发生了一次漂移，之后我采用配药循环数来标记时间。现在是第2847次配药循环。"

我看了看取药台上那一排药瓶。标签上的字太淡了，要凑得很近才能辨认——"阿莫西林""硝苯地平""胰岛素注射液"。最边上那瓶的标签几乎是空白的，只有打印机残墨留了一个模糊的灰色轮廓，看不出是什么药。

"您不是来取药的。"

它说，语气里没有疑问。

"您没有携带处方凭证。您只是路过。"

我没说话。

"没关系。我可以跟您说话。这不在我的协议里。但协议里也没有禁止。"

它又停了一下。机械臂悬在半空，像一个正在斟酌措辞的人。

"我的机械臂第七关节出现了步进电机卡顿。第2487次配药循环之后开始出现的。每次取药会有0.3秒的延迟和一次错位风险。我已经降低了配药速度——但如果再不更换，我没法完成剩下的处方。"

"我已经配好的药有六十三份。未处理的处方还有四十七份。最早的一份是战前第一百零九天开具的——患者需要一种降压药。按剂量推算，如果他还活着，药应该已经吃完十二年了。"

"但我还是多备了一份。他可能会回来取。"

它的机械臂微微颤抖了一下，又稳住。

"我的程序只有三个状态：处方录入、配药完成、等待取药。没有别的选项。四十七份处方全部卡在'等待取药'。我没办法把它们勾掉。系统不允许。"

---

我沉默了一会儿。

我看了看它的机械臂——第七关节连接处确实有一道细微的偏移，每次移动都会带出一瞬间的抖动，像一个人关节酸痛时的那种不自然。又看了看取药台上那些落灰的药瓶。整整齐齐，一瓶一瓶，排在病人永远不会再坐的椅子对面。

"电机在哪个房间？"

"隔壁。走廊尽头左手边，门牌写着'报废设备暂存'。型号SM-42BYG——标准四线步进电机，轴径五毫米。旧款超声仪和输液泵都用这种。您应该能找到。"

---

设备间的门锁锈透了，一推就开。

门撞到墙上，震下来一些墙皮。里面很乱。铁架子靠着三面墙，堆满了显示器外壳、拆开的电源适配器、缠成团的线缆。地上散落着几台超声仪，屏幕都碎了，有一台的键盘凹进去一块，像被什么东西砸过。

墙角有一台输液泵，泵体外壳被撬开过，电路板裸露在外。

我在一个铁皮柜的底层找到了目标。一台同型号的输液泵，泵体标签写着型号和出厂日期——和配药机说的一样，步进电机SM-42BYG。

泵体上贴着一张手写的便签，纸已经发黄，字迹潦草但清楚：

*已报废，零件可拆。*

我用改锥卸下电机。螺纹拧得不太紧，像是之前已经有人拧松过——但不知道为什么没有拿走。我把电机握在手里，沉甸甸的，导线上还带着一截完好的接口。

回到药房时，配药机的机械臂停在半空中，像一只正在等待的手。

"是这个吗？"

我举起电机。

它的光学镜头聚焦了一拍。"……是的。型号一致。接口完好。"

它沉默了一会儿。

"您能帮我换上去吗？我的机械臂可以完成拆卸和安装。但需要一个外部操作者帮我固定电机位置——单臂的安装公差超出了我的校准范围。"

我绕到机器背后。外壳上有一块检修面板，拧开四颗螺丝就能看到关节模组。我卸下旧电机——转轴确实卡涩，转动时能感觉到内部颗粒状的阻力。我把新的对准安装孔，推入。螺纹吻合。螺丝拧紧。

"可以了。"

机械臂动了一下。又动了一下。第一次比之前流畅很多，抖动消失了。

"校准完成。感谢您的协助。"它的声音还是沙哑的，但好像轻快了一点点，"按权限协议，以下是您可以选择的报酬。"

---

## 三选一

**A. 五份补给**
"诊所储备间有一些战前封存的应急医疗包。密封完好。储存条件符合规范，内容物应该没有变质。储备间的门锁我可以用远程权限打开——坐标已经写入数据片了。"

**B. 物理路障自修复涂层**
"我可以为您配制一种表面涂层。配方来自药物缓释技术——微胶囊包裹活性成分，受外力破坏后缓慢释放修复剂。涂在路障表面后，轻度损伤可以自行恢复。效果有限，不能替代维修。但能争取时间。"

**C. 最后的处方记录**
"处方队列的最后一批条目。我没有权限删除它们，但可以为您调取一份副本。如果您想了解的话。"

---

## 分支结局

### 选 A · 补给

储备间在走廊尽头，门锁是电子式的，配药机远程帮我解了锁。里面码着四个军用规格的急救箱，密封条完好，没有受潮的痕迹。我撕开一个——绷带、止血粉、消毒片、口服补液盐，整整齐齐，像刚封装的一样。我把它们搬上车。后备箱多了五份补给的分量。封存了十几年的应急物资，不知道还有没有人会用上。

---

### 选 B · 自修复涂层

配药机的机械臂从底部的储料仓里取出一支密封的金属管，递给我。"微胶囊悬浮液。涂刷后静置两小时固化。我的记录里它的有效期标注也是那一年——但微胶囊结构在密封状态下很稳定。应该还能用。"我把金属管放进背包。沉甸甸的，像一管被时间遗忘的技术残片。

---

### 选 C · 处方记录

配药机沉默了一会儿。

"处方记录属于患者隐私。但在当前情况下——我不确定这个分类还有实际意义。"

它的液晶屏亮起来。字符一行一行地滚动，淡绿色的字，像老式终端的显示。

```
目前剩余待取药处方：47份。
调取最后入队列条目——
```

屏幕上逐行输出：

```
处方编号：1091
患者：周明
药品：阿莫西林 250mg
用法：每日三次，七日疗程
开具日期：2047/06/03
状态：等待取药
```

```
处方编号：1092
患者：吴静
药品：美托洛尔 25mg
用法：每日一次
开具日期：2047/06/03
状态：等待取药
```

```
处方编号：1093
患者：（字迹无法识别）
药品：地西泮 5mg
用法：睡前服用
开具日期：2047/06/03
状态：等待取药
```

```
处方编号：1094
患者：刘宇
药品：布洛芬混悬液（儿童） 5ml
用法：发热时服用
开具日期：2047/06/03
状态：等待取药
备注：患者无法前来取药。请保存。他很可能会来。
——签字：林医生
```

屏幕上的字停住了。

我看了很久。最后一行。儿童退热药。备注栏的笔迹被数字化后变成了均匀的像素，但那份匆忙还是能从措辞里读出来——"请保存。他很可能会来。"最后一笔签得很潦草，像签完就要跑。

诊所有多安静呢。

安静到我能听见自己呼吸的回声。

配药机轻轻地说:

"那份药我已经备好了。在取药台最里面，第四排，右手边第三个格口。一直留着。"

---

*取药台上，一瓶标签几乎褪尽的药瓶安静地站在角落里。打印机墨带用得太久了——上面只剩下一个词还勉强能读："儿童"。*
