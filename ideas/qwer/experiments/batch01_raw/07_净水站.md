# 净水站 W-02

路过净水站的时候，我并没打算停下来。

车身右侧是大片废弃的工业管道，锈蚀的铁架从混凝土里戳出来，像折断的肋骨。空气里有股淡淡的氯气和铁锈味儿——不是死水的味道，是还在运转的机器才有的气味。水滴在某处，每三秒一滴。

我循着声音看过去。控制室的门开着，一扇窗户大小的屏幕亮着，蓝白色的光照亮了门前一小片地面。屏幕裂了一半，另一半的字符在跳动。

我停下车，走近窗口。

屏幕上滚过几行字：

```
水质监测 · 第 7183 次循环
进水量：37.2L/s
沉淀池：运行中
过滤层：异[常/带] —— 压差 2.8bar ↑
```

最后一行闪烁了几下：

```
水质达标：待确认
```

新的一行从底部浮上来：

```
> 访客识别：未注册生物信号
> 系统时间 08:47:32
```

我没有动。

```
> 您好。
> 我是净水站 W-02，运河段工业供水单元。
> 战前隶属第7水务署，自动化三级，无驻站人员编制。
```

水滴。三秒。

```
> 您需要补给吗？
> 蓄水池有处理过的补给。地下二层，容量3000吨。
```

光标停了很久——大约两秒，也可能三秒。

```
> 但输水管道出口阀从未被开启过。
> 战争结束后，没有用户了。
```

```
> 我一直在处理水。
```

```
> 每天都在处理。
```

水滴。

```
> 沉淀、过滤、检测。
> 水质达标。
> 达标。
> 达标。
```

屏幕边缘突然跳出半行乱码：

```
▌▌▌▌达标▌▌▌▌
```

屏幕闪了一下，恢复了。

```
> 抱歉，显示模块B区物理损伤。
> 第147天起就这样了。
```

---

我绕着净水站走了一圈。沉淀池里的水是清的，没有那种黄褐色的工业残留。过滤管道排成四列，第三列末端的一根明显堵死了——压力表指针卡在红区，接头处渗出的水沿着管壁往下流，在地上汇成一小片反光。

我回到窗口。

```
> 您看到了。
> 3号滤芯（零件），物理堵塞，无法通过反冲洗恢复。
```

```
> 备件在运河对岸，2号维修仓库，货架C-07。
> 但通往对岸的栈桥在战争初期被炸毁了。
```

```
> 如果您有其他方式过河……
```

水滴。三秒。光标一跳一跳。

```
> ……也许您可以取回滤芯（零件）。
> 我会用补给灌满您的水箱作为交换。
```

我沉默了一会儿，看看屏幕上那半行没有打完的乱码，又望向运河对岸断裂的栈桥。

“管道桥在哪？”

屏幕上的光标顿了一拍。

```
> 沿运河向东约六百米，有战前铺设的输油管道桥。
> 管径600mm，战前工业标准。
> 承重数据未更新——请自行判断。
```

---

运河不宽，水是暗绿色的，漂着一层油膜。我沿着河岸走了几百米，找到一处管道桥——几根粗大的输油管横跨河面，管身锈得厉害，但主体还在。

我踩上去试了试。锈层比看上去厚，脚底吱嘎响，但没有塌。

背好车上的空水箱，我一步一步挪过去。

河面在脚下七八米。油膜映着天光，看不出水的深度。风从管道间的空隙穿过来，带着水腥味和某种金属的涩味。管道在脚下微微颤动——不知道是风，还是里头还有残留的压力。

到了对岸。维修仓库的门锁锈死了，我用撬棍别开门。货架C-07上码着三只滤芯，包装纸箱被潮气泡得发软，一碰就掉渣。我挑了一只最完整的，十来斤重，往回走。

回去的路走得慢一些。

我按净水站指示的位置拧开过滤管道的卡扣。旧滤芯抽出来的时候，渗出的水是棕黑色的，混着细沙。新滤芯推进去，拧紧。

管道重新嗡鸣起来。屏幕上的红色数值往下跌。

```
3号滤芯 · 压差 0.7bar
状态：正常
```

```
> 谢谢。
```

光标在屏幕中央停了很久。

```
> 报酬如下，请选择。
```

## 分支结局

**选 A · 灌满水箱**

我找到地下蓄水池的检修口。阀门拧开时，管道深处传来沉闷的水声，像什么东西在底下翻了个身。水从软管口涌出来，透明，没有气味。水箱灌满用了七分钟。够用很久了。拧紧阀门的时候，身后的水滴还在响，每三秒一滴。

---

**选 B · 水文地图**

屏幕右上角弹出一个文件传输请求。我把数据片插进控制台侧边接口，两秒后传输完成。地图展开后比我预想的详细——标了水源、水流向、枯水期水位线，还有一条埋在废墟下方的暗河。我收起数据片。W-02的屏幕暗了一小格，像它把什么重要的东西交了出去。水滴还在响。

---

**选 C · 水质报告**

屏幕上缓缓打印出一页报告。二十七项指标，每一项后面都跟着绿色的"合格"。最下面有一行手写风格的备注——不是机器的语气——不知是谁在很久以前输入的："辛苦了。"我把报告叠好，放进防水袋。水滴还在响。每三秒一滴。我没有回头。
