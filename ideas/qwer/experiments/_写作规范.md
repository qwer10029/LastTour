# 终末旅行 · 剧情写作规范

## 世界观铁律（不可违背）

1. **地表无人类**。所有有对话能力的NPC必须是机器。
2. **末日无货币**。交易是资源换资源、劳动换物品、信息换生存。
3. **无社会秩序**。层与层之间没有人类管理，没有收费站，没有官僚。只有废墟、机器。
4. **玩家是克隆人**。18岁女性，被植入"志愿者"记忆，不知道自己是被昆仑程序一次次制造、一次次派出的消耗品。开局不揭示。

## 情感底色

- **静默的韧性**。不是热血，不是绝望。"世界很糟，但明天可能发现好玩的东西，we'll see。"
- NPC故事的核心张力：**程序在意义消失后仍在运转。**
- 每个NPC遭遇是一面镜子，从不同角度看同一个真相。

## 叙事结构模板

每个NPC故事包含：遭遇触发 → 环境锚点(1-2个物象) → NPC身份+困境 → 请求/任务 → 执行过程(感官细节) → 回报选择(三选一: A实用/B长远/C情感) → 各分支后果(一段不超四句，只呈现不评判)

## 文风铁律

1. **第一人称"我"**。主角存在感来自动作，非语言。全文台词不超五句。
2. **机器的声音**：正式、协议腔、军事/职务用语。人性通过停顿、卡壳、找措辞漏出。
3. **环境描写密度控制**：每句承载多重信息（废墟状态+时间流逝+情感色调）。无废话。
4. **不解释、不煽情、不说教**。后果呈现，不替玩家感受。
5. **留白**。最残酷的事实不让角色说透。哨兵不说"我要死了"，只说"我会继续守护"。
6. **一句话收束**。分支结局干净利落，戛然而止。

## 参考样例

见 `剧情/哨兵.md`。分析要点：
- 全文主角台词仅三句："仓库在哪？""拿到了。""——"
- 环境句即是情感句："风吹过半塌的旗杆。花盆里的枝条微微蠕动，像有自己的呼吸。"
- 三选一无道德评判：零件（实用）/蓝图（长远）/枝条（说不清的东西）
- 每个分支一段收束，不解释不煽情
- 机器的"人性"漏在停顿里："它顿了一下，像在翻找什么措辞"

## 文件命名

`<序号>_<NPC特征词>.md`，如 `01_清扫机.md`
